# FGS Share documentation

The guide for [FGS Share](https://github.com/franco-g-s/fgs-share), a fork of
[Gokapi](https://github.com/Forceu/Gokapi). It is reStructuredText, which GitHub renders: start at
[index.rst](index.rst). [fgs-share.rst](fgs-share.rst) covers what the fork adds.

To build it as HTML:

```bash
pip install -r requirements.txt
make html          # output in _build/html
```

Gokapi's own documentation, for plain Gokapi, is at https://gokapi.readthedocs.io/.

`design/` and `superpowers/plans/` are the design and the implementation plans of each part of the fork,
with the decisions taken during the work and each deploy record. `screenshots/` holds the README's images.
